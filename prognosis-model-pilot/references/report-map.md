## 覆盖与边界

已盘点24个项目，找到19组主报告，每组有Word和PDF；19份主PDF合计1,118页。报告文件检索还包含24项目结果目录内的一组副本，以及17/18/19/22的QC或GeneMANIA附属报告。按本轮检索口径共48个候选文件；附属报告和重复版本不算独立主报告。

19份Word均读取正文XML做结构解析，共提取约56.2万字符、13,028个非空XML段落（含表格和文本框，可能有封面兼容性重复文本）。逐项目阅读了数据来源、方法、候选/建模/验证或对应分类分析、总结、调整与质检的关键段落，并核对章节、图题、表格和软件列表结构。PDF用于实际页数核对；另检查02第6页、16第10页，以及24第1/35/69页的版式。

**这不是1,118页的逐页视觉审校，也不是对全部数字、引文或模型性能的重新验证。** 没有重跑分析，没有修改远端报告，没有批量下载Word/PDF或患者数据。保存的是提炼后的规范和索引；原始报告仍在服务器。

同日追加直接读图：通过Word OOXML图像关系定位并逐一目视查看19份主报告的嵌图，其中18幅为分析流程、10项目为病例纳排图。提取的是学习所需嵌图，没有下载整份Word或患者矩阵。逐图位置、数据流和对新项目的复用边界见 [report-flowcharts.md](report-flowcharts.md)；读图不代表图中所有节点已经执行或结果已经重算。

## 共用结构与写作习惯

早期报告多为“背景→分析方法→分析结果→总结→软件列表→方案调整→报告质检→参考文献”。较新报告改为“项目概述→分析结果→项目总结→项目调整→软件列表→报告质检→参考文献”；概述增加数据来源、研究目标、关键问题、设计特点与流程图。

结果段普遍按照目的、数据与比较、包/算法与阈值、定量结果、图表说明、结果目录展开。常见配套表包括候选或模型基因、PH检验、系数、通路中英文对照、质控前后数量、marker与细胞类型、软件版本用途，以及19项交付质检。

版式抽查见到：黑色粗体多级标题、居中图片及下方图题/注释；蓝色突出队列，绿色突出参数，红色突出数值结论和目录，早期来源段使用黄色标记。此为参考习惯，不能把颜色或旧模板数值当作统计/结论依据。Word XML重复封面文字是提取伪影，实际封面并不要求重复题名。

可操作的写作流程与交付检查见 [report-writing.md](report-writing.md)，可裁剪提纲见 [analysis-report.template.md](../assets/analysis-report.template.md)。

## 阅读中发现的迁移风险

这些例子用于决定写作核查项，不代表已经重算结果或判断整份报告无效。

| 来源位置 | 静态观察 | 新报告的处理原则 |
|---|---|---|
| 01“预后模型构建与评估”、16 PDF第10页单细胞质控 | 本项目是肺癌，段落中仍出现CRC称谓 | 疾病名、数据集名、图题及总结按同一项目字典核对 |
| 02“预后模型的验证”、09验证图题 | 文字或图题中出现与本节实际验证队列不一致的旧名称 | 图号、队列号与文件索引联动检查，不能只改正文 |
| 03候选筛选与富集、12候选筛选与富集、14候选筛选与富集 | 相邻段落使用不同的候选数量，例如03的19/71、12的32/66、14的588/759 | 以对应版本的候选列表和实际富集输入核查；冲突未解决前不选一个数字写进总结 |
| 多个报告的风险公式、验证切点与“泛化能力”表述 | 报告可能沿用线性公式或在验证队列重新求切点；本次代码学习也发现版本/尺度问题 | 评分公式跟随最终模型和预处理工件；阈值重新估计须单列，不能直接称为冻结模型的独立验证 |
| 02等报告的总结、部分题名/流程图 | 总结或计划含“实验验证”等词，不足以定位具体实验记录 | 数据集表达、药物计算与实际实验分别写；找不到实验记录时不继承“实验已证实” |
| 15、17、23“项目调整” | 报告披露因结果、数据或批次限制调整模块/队列 | 保留原因与影响；新的设计不自动为显著性而删除结果或交换训练验证 |
| 软件表与19项质检 | 多份表沿用固定版本或全部“无问题”样式 | 软件表从当前运行记录取得；质检逐项提供检查证据及真实状态 |
