# 数据与模型契约

这是从已有项目提炼的接口约定及适配要求，不是对服务器现有数据内容的验证。2026-10-21 的学习只读取源码与工件是否存在，没有载入患者级临床数据或表达矩阵。

## 原项目常见工件

| 阶段 | 常见文件 | 核查内容 |
|---|---|---|
| 新获取TCGA（默认） | `expression_SE.rds`、`counts.rds`、`tpm.rds`、`log2_tpm_plus1.rds`、`clinical_raw.rds`、`acquisition_manifest.rds` | TCGAbiolinks/GDC；完整下载及来源清单，不包含患者选样或已构造的生存终点；详见 [TCGA获取约定](tcga-acquisition.md) |
| bulk 整理 | `00_rawdata/fpkm.Rds`、`count.Rds`、`group.Rds`、`os.Rds` | 表达通常为基因×样本；文件名不保证数据尺度；临床列及顺序随项目变 |
| GEO 整理 | `01.clinical.txt`、`02.test_expr.txt` 等 | 样本常在行名/列名；有些文件用 `03.fpkm.txt`，不能统一假设 |
| 差异分析 | `03.DEGsList.txt`、`04.DEG.txt` 或其他编号 | 对比方向、FDR、效应量阈值、背景基因范围 |
| 候选整合 | `01.hubgenes.txt` | 是先验、DEG、细胞 marker、模块或虚拟敲除基因的哪个组合 |
| 单细胞 | `pbmc_done.Rds`、`R.05_scRNA.norm.umap_done.Rds` 等 | Seurat 版本、assay/layer、细胞注释、样本/患者字段、质控与整合参数 |
| 建模 | `06.lassogeneslist.txt`、`07.lassoresult.txt`、`*_model.RData` 等 | 分支可能最终用多变量 Cox，而非 LASSO 系数；查看实际评分脚本 |

## 输入规范

先确定表达矩阵方向。拟合常需“患者×特征”，原始 bulk 常为“基因×样本”。转置后用 ID 重排，不依据位置拼接。保存原 ID 到规范 ID 的映射，并核对重复患者、重复基因、多个探针到基因的聚合规则；TCGA 样本、aliquot 与患者层级不同，不能统一截断后默默去重。

生存信息至少明确 ID、时间、事件。`os_status` 在最终生存接口中为 0=删失、1=事件；从 Alive/Dead、TCGA 或 GEO 字段转换时保存原值及映射。OS、DFS、PFS 不得仅改列名后混用。时间单位由队列字典确定；原项目中的 `/365` 不构成新队列以天计量的证据。

表达尺度须记录来源及全部变换：是否 `log2(x+1)`、是否已归一化、是否做了按基因中心化、是否在训练中又调用了 `glmnet` 内部标准化。不要重复取对数或根据数值范围单独推断。

部门标准的“range一般不超过50”只能作为异常线索，不能作为log2处理或归一化的证明。优先复用来源明确的symbol列，不重复用bitr映射已正确注释的symbol；探针或Ensembl ID确需转换时记录平台/注释版本和一对多处理。原文TCGA的GENCODE v36为版本示例，应与实际获取数据的版本核对。

按部门默认，RNA-seq差异使用原始counts，非差异bulk分析统一预先选定的TPM/FPKM变换；不要将TPM/FPKM、按基因标准化数据或log2(count+1)当DESeq2原始counts。来源真实且符合特定方法契约的单细胞log-normalized assay及明确设计的VST不应误判成同一种输入；更换bulk表达契约需保留原始输入、依据及一致的下游变换记录。

单细胞至少保留 cell ID、sample ID、患者 ID（若有）、批次和细胞类型。Scissor 的 phenotype 可能是药物敏感/耐受，不能自动当生存；hdWGCNA 的细胞群、模块选择、软阈值与 metacell 分组应来自所选设计。虚拟敲除需要目标基因、细胞群与响应基因的筛选规则。

## 三基因集与下游接口

G1、G2以及启用的G3分别保存原始表、最终基因列表和来源/方法/阈值；统一基因命名空间与映射版本后保存逐基因归属表，包括`gene_id`、是否属于各集合及是否入候选。未启用G3标为不适用，不能用空集合参与运算导致所有候选被清空；启用但为空则是需要诊断的真实空集。交集数量、Venn/UpSet图与导出候选列表须一致。折内得到的集合同时保留对应折及训练患者信息。

高低风险标签只能由已记录的模型分数和冻结阈值产生，不按每个下游重新求最佳切点。下游表以患者/样本ID连接，保留原队列角色和每个模块实际可用患者数；额外的预后基因高低表达分组如有使用，单独命名和记录阈值，不能混称模型风险组。

列线图保存独立的联合模型工件，注明评分、临床因素、变量编码、缺失处理、预测时间点及基线生存；不能只有图片或只有基因系数。突变/TMB分析另需受检患者清单、突变过滤规则及相应负荷分母；免疫治疗真实反应评价另需治疗与反应/结局表。细胞通讯对象应保留关键细胞及其研究所需的其他细胞类型。

单细胞交付另保存细胞类型-marker-cluster映射、marker来源、未注释cluster的marker气泡图、质控前后每样本细胞/基因/线粒体统计及实际阈值。从配体受体复合体导出候选symbol时可展开成员，但保留复合体ID与原始关系，不把通讯算法中的复合体互作改造成独立单体互作。

## 建议保存的模型工件

新生成的实现可使用单个 RDS list 或相互引用的文件，至少明确：

- 模型类型、拟合对象、有序且唯一的特征、最终使用的系数来源。
- 表达转换、训练获得的中心/尺度、缺失值规则，以及哪些变换没有执行。
- 终点、时间单位、事件映射、训练与验证患者集合及折分。
- 特征筛选和调参规则、lambda/alpha（如适用）、种子、包版本、训练来源。
- 分数含义（线性预测值或相对风险）、方向、分组阈值及其学习来源。
- 若输出绝对生存概率：基线生存/风险、时间网格与居中约定。

对线性 Cox，先在训练尺度上得到 `eta = X_transformed %*% beta`；`exp(eta)` 是相应的相对风险尺度。二者不要混称绝对风险。输入列顺序必须按训练特征显式匹配。

缺少训练中心/尺度而系数来自显式 `scale(x)`，或者新队列缺入模基因时，不输出声称有效的预测。先列明所缺工件及可恢复路径。不能用零填充缺失基因、验证集独立标准化或重新拟合来冒充同一冻结模型。

部门原文“验证集最多缺失一个基因”不能作为删去该特征后继续使用同一模型的依据。即使只缺一个入模基因，也先处理测量/注释或寻找符合既定规则的输入；确需重建或更新模型时另存版本并重新评价，明确其与原冻结模型的区别。

## 续跑契约

只运行工件可追溯且契约满足的阶段。模型文件存在不证明其与脚本版本或当前样本一致。若旧流程只保存了一个全工作区，检查对象名、系数和预处理信息；新代码显式保存需要的对象。小样本检查可确认形状与顺序，但不能证明真实队列的方法有效或复现成功。
