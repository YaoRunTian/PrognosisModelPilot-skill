# 五个项目的参考 R 代码

此目录含用户授权的5个项目根目录R/Rmd参考脚本，共101份。原始绝对数据路径替换为 `<REFERENCE_DATA_ROOT>` 占位，原脚本的项目名、模块顺序、算法和相对输出命名尽可能保留；脚本仍可能依赖未打包的输入、函数、资源及服务器环境，**并非可直接运行的完整软件**。`source-index.tsv`记录原文件与草稿哈希及替换数。

`dependency-index.tsv`静态列出每个文件中的`library()`、`require()`和`package::function`名称；这只是依赖线索，既不保证动态调用和系统依赖被识别，也不代表包已安装或执行成功。所有参考脚本的路径占位需要依据本项目配置，数据、原始患者信息、数据库缓存及服务器环境未随包分发。

- `16_project_1449`：单细胞Scissor、hdWGCNA、bulk差异、交集和预后模型。
- `19_project_1533`：关键细胞、hdWGCNA、计算扰动、候选和预后模型。
- `22_job_0316`：预后模型、最终多因素Cox、风险分析和后续单细胞。
- `23_job_0727`：SIRT7、单细胞扰动、模型和单细胞下游。
- `24_job_0780`：TGFB1关键细胞、计算扰动、模型和下游分析。

在新项目中，先读取对应脚本的完整输入、输出与有效方法调用，按当前数据契约参数化或重新实现，保留真实原理与图表；不直接执行这些带路径占位、项目硬编码的参考脚本。需要的数据、资源、R包及模型步骤应按具体脚本实际读取并记录，不能仅根据本索引假定已随包提供。

本参考代码包不代表每条算法经过真实数据运行。16项目 `r.00_rawdata.R` 的 `list.files()` 行末多余数字已在参考副本删除，原始文件未修改；除此之外除路径脱敏外保留原实现。旧脚本还存在预测尺度、时间事件和外部截点等已记录问题，引用时须按技能契约修复并分别记录；不能把历史脚本直接当成已验证的正确实现。

具体例子：16项目历史生存ROC代码曾把预测风险组作为事件状态，且LASSO拟合使用的标准化与下游评分尺度可能不一致；部分外部队列重新选择最佳切点。相关位置和适配边界见 [代码地图](../code-map.md) 与 [工作流注意事项](../workflow-notes.md)。新建项目应按当前任务的事件编码、训练预处理、冻结验证和用户指定的单因素Cox→LASSO→多因素Cox执行，而非照搬这些历史问题。
